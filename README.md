# juliojmarquez.com

Static personal portfolio for GitHub Pages.

## Quick setup

1. Create a GitHub repository, for example `juliojmarquez.com`.
2. Upload `index.html` and `style.css`.
3. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
4. Add your custom domain: `juliojmarquez.com`.
5. In GoDaddy DNS, point the domain to GitHub Pages following GitHub's current custom-domain instructions.
6. Replace the placeholder LinkedIn, Instagram, GitHub and email links in `index.html`.

The site uses no framework, no database and no paid hosting.
